# Телеграма — мобільний клієнт

React Native / Expo-клієнт для Telegrama API. У застосунку є реєстрація, підтвердження email, вхід, список чатів, створення груп, пошук direct-контакту, вступ за ID і обмін повідомленнями через SignalR.

## Запуск

Установи залежності й запусти Expo з цієї папки:

```powershell
pnpm install
pnpm exec expo start --lan
```

Відкрий QR-код через Expo Go або натисни `a`, щоб запустити Android-емулятор. Перевірений шаблон базується на Expo SDK 57.

## Збірка APK для Android

Для тестового APK налаштований EAS Build профілем `preview`. Потрібен Expo акаунт і доступ до інтернету:

```powershell
npx eas-cli login
npx eas-cli build --platform android --profile preview
```

Під час першого запуску EAS може попросити створити або прив'язати проєкт та згенерувати Android signing credentials — погодься з цими кроками. Після завершення збірки відкрий посилання, яке покаже CLI, і завантаж APK на телефон. Android package ID: `com.artyur.telegrama`.

Цей APK призначений для встановлення й тестування напряму. Для публікації в Google Play потрібен окремий production профіль зі збіркою AAB.

## Підключення до API

Адресу сервера можна змінити в апці: натисни шестерню на екрані входу або відкрий профіль.

- Android-емулятор: `http://10.0.2.2:5022`
- iOS Simulator: `http://localhost:5022`
- Фізичний телефон: `http://<IP-комп'ютера-в-Wi-Fi>:5022`

Для фізичного телефона запусти API на мережевому інтерфейсі комп'ютера, наприклад:

```powershell
dotnet run --project .\Telegrama\Telegrama.csproj -- --urls "http://0.0.0.0:5022"
```

Телефон і комп'ютер мають бути в одній мережі. У Windows Firewall дозволь локальний вхідний трафік до порту `5022`. HTTP/cleartext налаштований для локального тестового середовища; для справжнього релізу потрібен HTTPS.

## Перевірка потоку email

1. Переконайся, що API запущений і для нього задані SMTP User Secrets.
2. У мобільній апці відкрий **Реєстрація**, створи акаунт і перевір вхідні/спам.
3. Введи шестизначний код у формі підтвердження.
4. Повернись до входу й увійди.
5. Відкрий чат або створи групу; два різні акаунти можуть переписуватись через SignalR.

Увага: React Native застосунок ходить прямо в API. Для нього не потрібне налаштування CORS, але для телефона потрібен доступ до API через LAN і firewall.
